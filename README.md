# KJO

Personal site: Visuals, Field Notes, Wardrobe, Character, Work, Projects. Built with Next.js (App Router), static pages, no database.

- All wording, page names, placeholders and image names live in `content/site.ts`.
- Images are in `public/img`. Swap a file or change its name in `content/site.ts`.
- Marks and symbols are in `public/mark`. Fonts are in `public/fonts`.
- Colour tokens are at the top of `app/globals.css`.
- The previous Kene OS dashboard is preserved in git history at commit `05bc2b7`.

Run locally: `npm install && npm run dev`.
